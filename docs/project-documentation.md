# Superstore Sales & Profit Analytics

## Project Objective

The objective of this project is to analyze Superstore sales and profitability using Microsoft Power BI.

## Key KPIs

- Total Sales
- Total Profit
- Total Orders
- Total Customers
- Profit Margin %

## Dashboard Analysis

### Sales Analysis
Analyze sales performance across categories, sub-categories, regions and states.

### Profit Analysis
Identify profitable and less profitable products, categories and regions.

### Customer Analysis
Analyze customer-level performance and order activity.

### Geographic Analysis
Analyze sales performance across different U.S. states.

## Dashboard Features

- KPI Cards
- Interactive Slicers
- Category Analysis
- Sub-Category Analysis
- Regional Analysis
- Product Analysis
- State-wise Sales Map

## Tools Used

- Power BI
- DAX
- Data Modeling
- Data Visualization
- Business Intelligence
